This package is a collection of different dynamic stall models. They are implemented either as a discrete ODE or a continuous ODE. The main purpose of this package was to implement the dynamic stall models for use in WATT.jl. 

Here is the list of models included:
- Beddoes-Leishman original (continuous)
- Beddoes-Leishman original (discrete)
- Beddoes-Leishman w/ Gonzalez's modification - AeroDyn implementation (discrete)
- Risø (Hansen 2004) (continuous)
- Risø (discrete)
- Larsen (continuous)
- Onera (continuous)
- Oye



- **Code:** [github.com/byuflowlab/DynamicSTallModels.jl](https://github.com/byuflowlab/DynamicStallModels.jl)
